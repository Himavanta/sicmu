# Sicmu — Bilibili 音乐播放器

## 项目定位

基于 Vue 3 + TSX 的油猴脚本，注入到 Bilibili 页面，利用 B 站 API 和用户登录态，实现一个独立的、优雅的音乐播放器。

## 核心原则

- 不依赖 B 站原有的界面 DOM
- 交互和 UI 必须优雅
- 全量利用 B 站音视频资源

## 功能规划

### 播放引擎

- [ ] 纯音频播放（DASH 音频轨）
- [ ] 视频播放（可选）
- [ ] 播放控制（播放/暂停/进度/音量）
- [ ] 播放模式（单曲/列表/随机/循环）

### B 站 API 集成

- [ ] Wbi 签名
- [ ] 收藏夹列表 → 歌单
- [ ] 视频合集 → 歌单
- [ ] 视频详情 / 音频流获取
- [ ] UP 主空间 / 用户关注

### 路由（vue-router memory 模式）

- [ ] `/now-playing` — 正在播放（全屏/迷你）
- [ ] `/playlist/:id` — 歌单详情
- [ ] `/playlists` — 歌单列表（收藏夹/合集）
- [ ] `/search` — 搜索
- [ ] `/settings` — 设置

### UI / 交互

- [ ] 浮层容器（拖拽、折叠、缩放）
- [ ] 歌单展示
- [ ] 播放界面（封面、标题、进度条）
- [ ] 全局快捷键
- [ ] 通知 / Toast

### 歌单管理

- [ ] 收藏夹映射歌单
- [ ] 合集映射歌单
- [ ] 播放队列
- [ ] 播放历史

## 技术栈

| 层       | 技术                         |
| -------- | ---------------------------- |
| 运行环境 | Tampermonkey / Violentmonkey |
| 构建     | vp pack (tsdown) → IIFE      |
| UI       | Vue 3 + TSX + SCSS           |
| 路由     | vue-router (memory history)  |
| 状态管理 | Pinia                        |
| 样式注入 | build:done hook 内联 CSS     |
| API 请求 | 原生 fetch (同域)            |
