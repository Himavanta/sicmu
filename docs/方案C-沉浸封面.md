# 方案 C：沉浸封面模式

> 当前推进的开发方案。

---

## 布局

```
默认（无交互）：
┌──────────────────────────────┐
│                              │
│  封面 / 渐变 (120px)         │  ← 只有横幅
│                              │
├──────────────────────────────┤
│ 播放列表 (≡ 点击切换)         │
└──────────────────────────────┘

Hover 时（封面区域内浮现）：
┌──────────────────────────────┐
│  ┌────蒙版────────┐          │
│  │ 标题           │          │
│  │ ──●── 1:23/3:45│          │  ← 全部在 120px 内浮层
│  │ ◁ ▶ ▷  🔊≡   │          │
│  └────────────────┘          │
├──────────────────────────────┤
│ 播放列表                      │
└──────────────────────────────┘
```

## 结构

整个组件只有两个区域：

| 区域         | 高度  | 说明                                 |
| ------------ | ----- | ------------------------------------ |
| **封面横幅** | 120px | 渐变/封面/播放器，hover 浮现控制浮层 |
| **播放列表** | 可变  | 通过 ≡ 按钮切换展开/收起             |

## 交互

| 状态   | 封面横幅                      | 播放列表  |
| ------ | ----------------------------- | --------- |
| 默认   | 封面/渐变                     | 收起      |
| Hover  | 浮现蒙版 + 标题 + 进度 + 控制 | 不变      |
| 点击 ≡ | 不变                          | 展开/收起 |
