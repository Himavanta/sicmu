# 方案 A：经典纵向卡片（主题系统基础）

## 布局

```
┌──────────────────────────┐
│ ┌──────────────────────┐ │
│ │                      │ │
│ │   专辑封面（圆角）      │ │  ← 封面占视觉主体，可替换不同主题
│ │                      │ │  （复古像素 / 黑胶 / 磁带 / CD…）
│ └──────────────────────┘ │
│                          │
│ 歌名                     │
│ 艺术家                   │
│                          │
│ ──────────●───────       │  ← 进度条
│ 1:23            3:45     │
│                          │
│    ◁    ▶    ▷    🔊≡   │  ← 控制行
└──────────────────────────┘
```

## 特点

- 封面在上、控制在下，布局稳定，是良好的"画框"结构
- 更换封面样式（图片 / 渐变 / 像素 / 黑胶…）即可实现不同主题
- 主题只需替换 `PlayerArtwork` 样式和配色，骨架不动
- 适合嵌入侧边栏，自然纵向排布
- 播放列表展开在卡片下方
