## 🎵 最直接的方案

### **方案1：直接用 `<audio>` 标签播放MP4视频**

**MP4视频天生可以被音频标签播放！** 浏览器会自动忽略视频部分，只播放音频。

```html
<!-- 就这么简单 -->
<audio controls>
  <source src="视频URL.mp4" type="audio/mpeg" />
</audio>
```

或者用JavaScript：

```javascript
const audio = new Audio()
audio.src = 'https://xxx.mp4' // 直接用视频URL
audio.play()
```

### **方案2：获取MP4格式的视频流**

从API获取时，**直接请求MP4格式**（而不是DASH）：

```javascript
// 调用 playurl API
const response = await fetch('https://api.bilibili.com/x/player/wbi/playurl', {
  params: {
    bvid: 'BV...',
    cid: 123456,
    fnval: 1, // 🔑 请求MP4格式（不是4048的DASH）
    qn: 16, // 360P最低清晰度，文件最小
  },
})

// response.data.durl[0].url 就是MP4视频地址
const mp4Url = response.data.durl[0].url

// 直接丢给 <audio> 标签
audioElement.src = mp4Url
```

### **方案3：最小化带宽 - 混合策略**

如果想最省流量，结合两种方案：

```javascript
// 1. 尝试获取MP4（最兼容，文件相对小）
async function getAudioUrl(bvid, cid) {
  try {
    // 先试MP4
    const mp4Response = await getPlayUrl({
      fnval: 1,
      qn: 16, // 最低360P
    })

    if (mp4Response.data.durl?.[0]?.url) {
      return mp4Response.data.durl[0].url
    }
  } catch (e) {
    // 降级到DASH音频
    const dashResponse = await getPlayUrl({ fnval: 4048 })
    const audioTrack = dashResponse.data.dash.audio[0]
    return audioTrack.baseUrl
  }
}
```

## 📊 B站的流媒体格式

根据文档，B站主要返回两种格式：

### **1. MP4格式（最常见）**

```
fnval=1  →  单个完整MP4文件
durl: [{ url: "https://xxx.mp4?expires=..." }]
```

- ✅ **这就是普通文件**，不需要任何库
- `<audio>` 标签直接可以播

### **2. DASH格式（新视频）**

```
fnval=16  →  DASH流（视频和音频分离）
dash: {
  video: [...],      // 多个视频流段
  audio: [...]       // 多个音频流段
}
```

- ⚠️ **这是分段的m4s文件**，需要处理

---

## 🎬 DASH格式需要库吗？

**简短答案：** 取决于你的需求

### **场景1：只要音频 → ❌ 不需要库**

```javascript
// DASH中的音频已经是完整可播放的
const audioUrl = dash.audio[0].baseUrl
audio.src = audioUrl // 直接用！
```

### **场景2：要播放视频 → ✅ 需要库**

DASH格式的视频是**分段m4s文件**，需要库来：

- 下载多个分段
- 合并成完整视频
- 处理缓冲和seek

## ⚠️ 但要注意的细节

### **问题1：DASH音频段可能很大**

如果音频URL无法直接在`<audio>`中播放（跨域或格式问题），可能需要**Range请求**（渐进式下载）：

```javascript
// 这通常是浏览器自动处理的
// 但如果你的服务器要代理，需要支持Range请求
fetch(url, {
  headers: {
    Range: 'bytes=0-1023', // 只下载前1KB
  },
})
```

### **问题2：URL有过期时间**

```

```

- ✅ MP4格式：120分钟内有效
- ✅ DASH格式：同样有效期
- **需要：** 用户不能离线播放，要及时刷新

```javascript
// 只在需要处理DASH分段时才用
async function playDashAudio(audioUrl) {
  const audio = new Audio()
  const ctx = new (window.AudioContext || window.webkitAudioContext)()

  // 方案1：简单粗暴 - 直接用（推荐）
  audio.src = audioUrl
  audio.play()

  // 方案2：如果上面失败，用MediaSource API
  if (!audio.canPlayType('audio/mp4')) {
    const ms = new MediaSource()
    audio.src = URL.createObjectURL(ms)

    ms.addEventListener('sourceopen', async () => {
      const sb = ms.addSourceBuffer('audio/mp4; codecs="mp4a.40.2"')
      const data = await fetch(audioUrl).then((r) => r.arrayBuffer())
      sb.appendBuffer(data)
      ms.endOfStream()
    })
  }
}
```
